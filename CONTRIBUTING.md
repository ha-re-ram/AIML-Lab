# Contributing to AIML Lab

First off, thank you for considering contributing to this repository! Your efforts help in making this resource better for the academic community.

## How to Contribute

1.  **Fork the Repository**
    Click the 'Fork' button at the top right of this page to create a copy of this repository on your GitHub account.

2.  **Clone Your Fork**
    ```bash
    git clone https://github.com/YOUR_USERNAME/AIML-Lab.git
    cd AIML-Lab
    ```

3.  **Create a New Branch**
    ```bash
    git checkout -b feature/your-feature-name
    ```

4.  **Make Your Changes**
    - Improve code documentation.
    - Add new lab experiments.
    - Fix existing bugs or issues.

5.  **Commit and Push**
    ```bash
    git add .
    git commit -m "feat: added new clustering experiment"
    git push origin feature/your-feature-name
    ```

6.  **Create a Pull Request**
    Open a Pull Request on the original repository's `main` branch.

## Standards

- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) style guidelines for Python.
- Include comments and documentation (docstrings) for complex logic.
- Ensure Jupyter Notebooks are cleared of output before committing (optional but clean).

---

Thank you for your contribution! 🚀
